## Ce que je construis

> *Pas juste du code qui tourne — du code qui tient.*

Chaque projet que j'ouvre commence par une question : **est-ce que ce truc va tenir en production ?**
Migrations de versions, architecture en couches, APIs qui ne cassent pas à la moindre charge — c'est ce qui m'intéresse.

Actuellement en stage fullstack chez **ZubHub (Paris)** : Java 21→25, Spring Boot 3→4, Kafka, Redis, PostgreSQL, React.
